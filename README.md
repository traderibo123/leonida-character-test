# Leonida Character Test

A free, fan-made GTA VI personality quiz. This site is static HTML, CSS, and JavaScript; it needs no build step.

## Publish with GitHub Pages

1. Upload `index.html` and the complete `images/` folder to the root of a GitHub repository.
2. Open the repository’s **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select your main branch and the `/(root)` folder, then save.
4. GitHub Pages will show the published site URL on that settings page.

Keep the image filenames and folder structure unchanged so the character portraits and image backgrounds load correctly.
